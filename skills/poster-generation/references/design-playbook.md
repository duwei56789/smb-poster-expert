# 海报设计手册（商业海报）

## 一、版式分区（竖版通用骨架）

从上到下，用 flex 纵向排列，页脚 `margin-top:auto` 贴底：

| 区块 | 作用 | 高度占比参考（A2 竖版） |
|---|---|---|
| 顶部品牌条 | Logo/品牌名 + Slogan | 5% |
| 主标题区 | 活动主题、主标题、副标题 | 12-18% |
| 主视觉 | 产品/场景大图 | 25-35% |
| 数据/权益条 | 核心数字、优惠、资质，横向等分 | 6-8% |
| 卖点区 | 3-6 个卖点卡片，2 列或 3 列网格 | 20-25% |
| 补充区 | 产品矩阵、金句、适用场景 | 10-15% |
| 页脚 | 联系方式、二维码、门店信息 | 6-8% |

要点：内容总量要撑满画布。A2 画布很高，区块内容偏少会导致下半部大片留白——宁可增加真实卖点与场景，也不要靠空间距硬撑。

## 二、字号层级（A2 竖版，mm 单位）

| 层级 | 字号 | 用途 |
|---|---|---|
| 品牌名 | 10-12mm | 顶部品牌条 |
| Slogan | 5-6mm | 顶部右侧 |
| 主标题 | 18-22mm | 核心主题，可给关键字换主色 |
| 副标题 | 9-11mm | 利益点补充 |
| 引题/装饰 | 4-5mm | 金色标签、小标题 |
| 区块标题 | 7-8mm | 卖点区/补充区标题 |
| 卖点短标题 | 5-6mm | 卡片标题 |
| 正文 | 3.8-4.2mm | 卡片说明，行高 1.5-1.6 |
| 页脚大字 | 7-8mm | 页脚主信息 |
| 页脚小字 | 3.5-4mm | 页脚说明 |

横版（A3/A4 横版）按画布等比缩小。朋友圈竖图用 px，主标题 80-110px、正文 30-38px。

## 三、配色方案

用 `:root` 定义语义化变量，全篇引用，方便一键换色：

```css
:root{
  --green:#1E6B4F;   /* 主色 */
  --green-d:#16523D; /* 主色深 */
  --gold:#C6A15B;    /* 强调/金标 */
  --ink:#24312B;     /* 正文墨色 */
  --muted:#6E7A73;   /* 次要文字 */
  --cream:#F7F4EC;   /* 卡片底 */
  --paper:#FFFDF8;   /* 纸张底 */
}
```

常用行业配色：
- **家居/环保/健康**：墨绿 + 金 + 米白（自然、高端）
- **餐饮/促销**：红/橙 + 暖黄 + 白（刺激食欲、热闹）
- **科技/制造**：深蓝 + 青 + 白（专业、可信赖）
- **教育/母婴**：暖橙/马卡龙 + 白（亲和、温暖）

配色原则：主色定调、强调色点睛（≤10% 面积）、正文用深色保证可读、底色留白。避免高饱和撞色堆砌。

## 四、中文排版要点

- 字体栈：`"Microsoft YaHei","PingFang SC","Hiragino Sans GB",sans-serif`。
- 字距：`letter-spacing` 标题 0.8-1.5mm、英文标签 1.5-2mm，提升精致感。
- 行高：正文 1.5-1.6，标题 1.1-1.2。
- 对齐：同一区块左对齐基线统一；网格卡片等高。
- 留白：区块间距用 mm 显式控制，避免 `space-between` 造成不可控空隙。

## 五、主视觉与水印

- 用 ImageGen 生成时 prompt 结尾加「无任何文字、无logo、无水印」，但仍可能带平台水印。
- 成品中用右下角渐变色块 `.wm-cover`（`linear-gradient(135deg,transparent, rgba(纸色,.95) 42%)`）遮盖水印区。
- 商用物料优先用品牌官方实景图，避免 AI 素材与品牌合规风险。

## 六、二维码与 CTA

- 未拿到落地页链接时，二维码用占位方块并明确标注「占位，不可直接商用」。
- CTA 文案要具体：扫码预约 / 到店体验 / 立即咨询 / 领取优惠。
- 拿到链接后用二维码生成工具产出真实二维码替换占位。
